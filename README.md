# Little Box of Chaos

Uma pequena caixinha virtual cheia de surpresas, carinho e um pouquinho de caos!

O **Little Box of Chaos** é um projeto web interativo criado para transformar uma simples caixa de presentes em uma experiência digital divertida, delicada e inesperada.

## Sobre o projeto

A ideia é simples: abrir uma caixinha virtual e descobrir o que existe dentro dela.

Com uma estética em tons de rosa pastel, lilás e branco, o projeto combina animações 3D, interatividade e mensagens divertidas para criar uma experiência que pode ser compartilhada com amigos.

## Funcionalidades

- Caixa de presentes 3D interativa com laço decorativo.
- Tela inicial de boas-vindas.
- Animação de abertura da caixa.
- Quatro presentes interativos.
- Mensagens personalizadas e fixas para cada presente.
- Surpresa secreta ao finalizar a experiência.
- Interface adaptada para computadores e dispositivos móveis.

## Tecnologias utilizadas

- **HTML5** — Estrutura da aplicação.
- **CSS3** — Estilização, cores e animações.
- **JavaScript** — Interatividade e lógica da experiência.
- **Three.js** — Renderização e manipulação da caixa tridimensional.

## Como executar

1. Clone o repositório ou baixe os arquivos do projeto.
2. Abra a pasta no Visual Studio Code.
3. Execute o arquivo `index.html` utilizando a extensão Live Server.
4. Interaja com a caixinha e descubra as surpresas!

## Objetivo

O projeto foi desenvolvido como uma atividade criativa e pessoal, sem fins comerciais, com o objetivo de explorar recursos de desenvolvimento web, experimentar animações tridimensionais e criar uma experiência divertida para compartilhar com amigos.
